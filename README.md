# MoneyMaster 

**Бесплатное, простое и быстрое веб-приложение для учёта личных финансов.**

## Актуальность темы

В современном мире управление личными финансами становится необходимостью для каждого человека. По данным статистики, более 60% людей не ведут учёт своих доходов и расходов, что приводит к необоснованным тратам и финансовым проблемам.

**Существующие решения** (например, «Дзен-Мани», «CoinKeeper») имеют следующие недостатки:
- Требуют платной подписки
- Перегружены сложным функционалом
- Собирают много личных данных
- Имеют медленную работу

Проект **MoneyMaster** решает эти проблемы, предлагая бесплатный, интуитивно понятный и быстрый инструмент для контроля бюджета.

## Целевая аудитория

Приложение ориентировано на следующих пользователей:

- **Студенты** – контроль стипендии и подработок
- **Молодые специалисты** – планирование бюджета после зарплаты
- **Семьи с детьми** – учёт общих расходов
- **Пенсионеры** – простой и понятный интерфейс

**Ключевая характеристика аудитории:** отсутствие финансового образования, потребность в интуитивно понятном интерфейсе.

## Функциональные возможности

### Основной функционал (обязательный)

1. Регистрация и авторизация пользователей
2. Добавление доходов (зарплата, подарки, кэшбэк)
3. Добавление расходов (еда, транспорт, развлечения)
4. Просмотр текущего баланса
5. Категории операций (предустановленные + свои)
6. Фильтрация по дате и категории
7. Простая статистика (диаграмма расходов)

### Дополнительный функционал (при наличии времени)

8. Экспорт отчёта в Excel
9. Ежедневные напоминания
10. Тёмная тема интерфейса
